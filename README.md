# 萌弈少儿围棋乐园 (Kid Go Paradise) ⚪⚫

专为 12 岁以下儿童量身打造的趣味围棋启蒙应用。采用 **Web 先行架构**，基于 **React + TypeScript + Tailwind CSS + HTML5 Canvas**，支持零成本离线运行，并已内置 **Capacitor** 配置文件，可直接打包输出为安卓平板 APK。

---

## 🌟 核心特色与功能

### 1. 视网膜高清 Canvas 棋盘 & 少儿防误触交互
- **Retina 自适应高刷渲染**：支持 `devicePixelRatio` 动态缩放，画质细腻无毛刺。
- **智能防误触**：
  - 7×7 与 9×9 小盘：大触控区域，直接点击即落子，手感畅快；
  - 13×13 与 19×19 大盘：采用“轻触点选显示虚影 + 悬浮确认落子”机制，彻底杜绝误触。
- **吃子粒子散开动效**：每当发生吃子或提子，棋子位置炸裂出彩色小星星，视觉反馈拉满。
- **数气光点辅助**：一键开启“数气光点”，实时用绿色光圈高亮显示当前棋子的所有气口。

### 2. 纯代码合成 Web Audio 零延迟音效
- 基于浏览器原生 Web Audio API 程序化振荡合成，**无需下载任何音频文件，零网络加载延迟**：
  - **落子声**：三角波木质共振 + 带通白噪声冲击，真实还原玉石敲击实木棋盘声；
  - **吃子声**：C5-E5-G5-C6 清脆上行叮咚音；
  - **胜利号角**：通关与胜负结算时的高潮庆祝和弦；
  - **失误声**：柔和低音提示，不给孩子带来挫败感。

### 3. 四阶认知梯度闯关地图（冒险岛）
严格对齐少儿心理认知阶梯，关卡进阶环环相扣：
- **第一章：气的秘密与吃子**（角上紧气、边上线打吃、单子逃跑长气）
- **第二章：趣味吃子小战术**（神奇双打吃一石二鸟、关门吃）
- **第三章：安全禁区与打劫**（认识老虎嘴、禁着点、同形打劫规则）
- **第四章：做眼与死活**（真眼与假眼、分割做两眼彻底活棋）
- 通关自动计算 1~3 颗金星，支持本地离线自动持久化保存进度。

### 4. 萌宠吃子大作战（离线自研弱 AI 陪练）
纯本地轻量状态机 + 规则启发式 MCTS，断网秒跑，专为少儿调校：
- **🐰 萌萌兔 (25K)**：7×7 棋盘，先吃 1 子获胜。AI 动作呆萌，故意漏破绽，激发孩子吃子兴趣。
- **🐻 憨憨熊 (20K)**：9×9 棋盘，先吃 3 子获胜。会做基本防守，学会使用双打吃克敌。
- **🦊 聪聪狐 (15K)**：9×9 棋盘，先吃 5 子获胜。攻守兼备，注重眼位与气数。
- 动态语音气泡与正向鼓励反馈。

### 5. 自由棋盘与 SGF 题谱工具
- **支持 7×7、9×9、13×13、19×19 路数随时切换**。
- **形势判断与目数推算**：实时洪泛算法评估双方控制地盘目数与提子数。
- **标准 SGF 格式导入/导出**：支持家长与老师将自己出的死活题以 `.sgf` 文件直接导入给孩子练题。

## 📱 转化输出为安卓平板 APK (Capacitor)

本项目已预置 `capacitor.config.ts`，如需输出 Android 原生工程及 APK，请在当前目录下执行以下标准化流程：

```bash
# 1. 安装 Capacitor 原生 Android 支持库
npm install @capacitor/core @capacitor/cli @capacitor/android

# 2. 构建最新 Web 静态资源
npm run build

# 3. 初始化并生成 Android 原生工程目录
npx cap add android

# 4. 同步 Web 代码至 Android 工程
npx cap sync

# 5. 在 Android Studio 中打开并一键打包输出 APK
npx cap open android
```

> **平板沉浸式提示**：在生成的 Android 工程 `AndroidManifest.xml` 中将 Activity 的 `android:screenOrientation` 设置为 `sensorLandscape`（横屏锁定），并在系统样式中启用全屏隐藏状态栏，即可拥有如原生 App 般的全屏体验！
